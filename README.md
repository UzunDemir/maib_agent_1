# MAIB Investment Advisor Agent

## Описание

Агент-консультант по инвестициям для клиентов банка **MAIB** помогает пользователям принимать обоснованные решения по выбору инвестиционных продуктов. Агент анализирует данные клиента (цели, уровень риска) и предоставляет рекомендации по выбору продуктов банка, таких как депозиты, облигации и инвестиционные фонды.

### Основные функции:
- Сбор информации о клиенте (финансовые цели, рисковый профиль).
- Оценка доходности и рисков различных инвестиционных продуктов.
- Рекомендации по созданию сбалансированного инвестиционного портфеля.
- Визуализация прогнозируемой доходности и рисков.
- Ответы на вопросы клиента в формате диалога.

## Стек технологий

- **Streamlit** — для разработки веб-интерфейса и деплоя.
- **LangChain** — для обработки запросов на естественном языке.
- **Python (Pandas, NumPy, sklearn)** — для расчёта рисков и прогнозирования доходности.
- **Matplotlib / Plotly** — для визуализации данных.
- **SQL / API** — для интеграции с данными банка.
